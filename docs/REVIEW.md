# Вычитка событий и выборов

Цель: каждое событие логично по сюжету и эпохе, выборы без очевидно лучшего варианта, эффекты соответствуют тексту.
Правки вносятся через `tools/patch_events.py` (патч по id), после — `tools/build.py`, `tools/build_game.py`.

**Первый проход (28.10.2026): все 22 раздела, 494 события.** Исправлено ~90 событий:
тексты, привязанные к полу («жена», «свекровь», «приводи его»), к эпохе («десятка» в 90-е, «Архипелаг» в 1987-м),
к месту (Ленинград для москвичей, Сухуми для всей Грузии, Крым для всей Украины), служебные пометки в тексте («раздел PRIV», «§7.7»),
выборы без цены (всегда выгодный вариант), эффекты наоборот (выкуп из ломбарда добавлял деньги, проигрыш в казино радовал),
одинаковые варианты (кредит «в рублях» и «в у.е.»), предложения не по адресу (банк — любому рабочему).
