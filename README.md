# Время перемен

Кинохроника одной жизни, 1986–1999. Тебе выпадает случайный человек из 280 миллионов жителей СССР — республика, возраст и семья по реальной статистике. Дальше — перестройка, распад, девяностые: события, решения, деньги, которые съедает инфляция.

Играть: https://xdestrix44444-cmyk.github.io/vremya-peremen/

## Что где

| Папка | Что внутри |
|---|---|
| `game/` | Сама игра: `index.html`, `engine.js` (симуляция), `ui.js` (интерфейс), `data.json` (собранные данные). Именно она выкладывается на GitHub Pages и открывается в Telegram |
| `data/events/*.yaml` | ~490 событий по разделам — главный источник контента |
| `data/*.yaml`, `data/tables/` | Шкалы, флаги, имущество, профессии; демография ООН, экономика и курсы Всемирного банка |
| `tools/` | Сборка и проверка: `build.py` (валидация событий → `EVENTS.md`), `build_game.py` (→ `game/data.json`), `simulate.py` (прогон тысяч жизней), ETL-скрипты таблиц |
| `CONCEPT.md` | Весь дизайн игры и принятые решения |
| `docs/` | Макеты и доска стилей |

## Как менять события

```sh
python3 -m venv .venv && .venv/bin/pip install pyyaml
.venv/bin/python tools/build.py        # проверить события, пересобрать EVENTS.md
.venv/bin/python tools/build_game.py   # пересобрать game/data.json
.venv/bin/python tools/simulate.py     # прогнать симуляцию, отчёт в reports/
```

Локально игру можно открыть так: `cd game && python3 -m http.server 8000` → http://localhost:8000 (просто двойной клик по `index.html` не сработает — браузер не даст загрузить `data.json`).

После `git push` в `main` GitHub сам выкладывает `game/` на Pages (`.github/workflows/pages.yml`), через минуту-две обновление видно и в Telegram.

## Как сделать мини-приложение в Telegram

Игра уже умеет работать внутри Telegram: разворачивается на весь экран, красит шапку в цвет плёнки, системная кнопка «Назад» закрывает разделы и шторки, при выборе — отклик вибрацией, при попытке закрыть посреди жизни Telegram переспросит, а в финале есть кнопка «Поделиться» итогом. Вне Telegram всё это просто не включается.

1. **Создать бота.** В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot` → название (например «Время перемен») → имя, оканчивающееся на `bot`. BotFather пришлёт токен — **его никуда не коммитить**: для мини-приложения без своего сервера токен вообще не нужен.
2. **Создать Mini App.** В BotFather `/newapp` → выбрать бота → название, описание, картинка 640×360 → **Web App URL**: `https://xdestrix44444-cmyk.github.io/vremya-peremen/` → короткое имя (например `play`). Игра будет открываться по ссылке `https://t.me/<имя_бота>/play`.
3. **Кнопка в чате с ботом.** В BotFather `/mybots` → бот → *Bot Settings* → *Menu Button* → тот же URL и подпись «Играть». Теперь в чате с ботом слева от поля ввода будет кнопка запуска.
4. **Ссылка «Поделиться».** В `game/ui.js` вписать имя бота и короткое имя приложения:
   ```js
   const TG_BOT = 'imya_bota', TG_APP = 'play';
   ```
   закоммитить и запушить — тогда «Поделиться» в финале будет звать друзей прямо в игру.
5. *(по желанию)* `/setdescription`, `/setabouttext`, `/setuserpic` — описание и аватар бота.

Telegram сам подхватывает новую версию: при запуске игра сверяет свой номер сборки с `version.json` и, если вышла новая, перезагружается на неё (номер подставляет `pages.yml`).
