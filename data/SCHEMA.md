# Формат событий (`data/events/*.yaml`)

Один файл — один раздел каталога. Справочники: `stats.yaml` (шкалы, задатки, республики, профессии), `flags.yaml` (флаги).
После правок запускать `tools/build.py`: он проверяет данные и собирает `EVENTS.md`.

```yaml
- id: BIZ-09                 # уникальный код
  type: choice               # news | scene | choice | offer
  fixed: true                # только для хроники: срабатывает у всех подходящих в указанный месяц
  when: {from: 1992, to: 1998, month: 8}   # month — необязательно
  where: [RU, UA]            # нет поля — все республики
  who:                       # условия появления, всё необязательно
    age: [18, 60]
    exp: ">5"                # годы опыта в текущей сфере (CONCEPT §3.11a)
    money: ">50"             # сбережения в средних месячных зарплатах
    years: [1995, 1999]      # только для вариантов выбора: в какие годы вариант доступен
    sex: m
    role: [young, adult]
    job: [kiosk]
    not_job: [army]          # занятие не из списка
    edu: [university]
    stats: {ties: ">50", fit: "<40"}
    traits: {charm: strong}
    flags: [business]        # все должны быть
    not_flags: [brigade]     # ни одного не должно быть
    any_flags: [activist, official]   # хотя бы один должен быть
  weight: 2                  # частота для случайных событий, по умолчанию 1
  chance: 0.04               # вместо weight: годовая вероятность для подходящих, вне бюджета событий
  focus: health              # сцена фокуса: бывает, только когда выбран этот фокус (или список фокусов)
  repeat: true               # может случаться больше одного раза
  trigger: engine            # событие-переход: его выпускает движок (дембель, диплом, пенсия), в случайный пул не попадает
  text: "Сцена уровня Б"
  variants: ["…", "…"]     # конкретные ситуации, движок выбирает одну (вместо перечислений)
  texts_by_age: {kid: "…", school: "…"}   # другой текст для возраста (kid, school, young, adult, pension)
  third_person: true         # глаголы в текстах про другого человека — не менять по полу игрока
  effects: {health: -2, money_m: -1}       # шкалы из stats.yaml и money_m (в месячных доходах)
  sets: [flag]               # поставить флаги
  clears: [flag]             # снять флаги
  choices:
    - text: Платить
      who: {age: [18, 60]}               # условие показа варианта, необязательно
      memo: "Строка для итога года"     # как этот выбор запомнится в «Твой год»
      effects: {money_m: -2}             # выбор без риска
    - text: Отказать
      check: {base: 40, ties: 0.3, strength: 10, served: 10, year: {1993: -10}}
      success: {text: "Отстали", effects: {ties: 5}}
      fail: {text: "Ларёк сгорел", effects: {money_m: -8}, sets: [stubborn]}
    - text: Найти свою крышу
      outcomes:                          # больше двух исходов
        - {w: 50, mods: {ties: 0.5}, text: "Помогли", sets: [own_roof]}
        - {w: 30, text: "Стало хуже", effects: {money_m: -4}}
        - {w: 20, text: "Новая крыша хочет долю", effects: {money_m: -2}}
```

Флаг с `engine: true` в `flags.yaml` читает движок, а не события (например, `official_record` для стажа).

**Проверка (`check`, `mods`)**
- `base` — базовый шанс успеха в процентах или базовый вес исхода.
- Шкала (`ties: 0.3`) — добавка за каждый пункт выше 50 (ниже 50 — штраф). У Известности и Внимания закона отсчёт от нуля: `fame: 0.5` даёт +0,5 за каждый пункт.
- Задаток (`strength: 10`) — сильный +10, слабый −10.
- Флаг (`served: 10`) — добавка, если флаг стоит.
- `exp: 2` — добавка за каждый год опыта в текущей сфере.
- `year`, `region`, `edu` — добавки по году, республике, уровню образования (`edu: {university: 15}`).
- Шанс в `check` (получилось / не получилось) зажимается в 5–90%. Веса в `outcomes` берутся как есть, без зажима: так редкая гибель остаётся редкой. Метка `rare: true` оставлена для наглядности у лотерей.

**Исход** (а также вариант выбора и само событие) может содержать: `text`, `effects`, `sets`, `clears`, `job` (новое занятие из stats.yaml), `edu` (уровень образования, который получает или начинает получать), `promote: true` (повышение на ступень должности), `item` (имущество из `data/items.yaml`: `{add: id}`, `{remove: id}`, `{remove_group: car}`), `asset` (актив: `{kind, sector, value}` — добавить стоимостью в средних зарплатах, или `{kind, scale}` — умножить стоимость, `scale: 0` — продать или потерять), `move` (переезд в республику), `end` (`death` — гибель, `abroad` — уехал за пределы бывшего СССР), `ref` (ссылка на таблицу в концепте).
